Loss Function

The loss function serves as a measure of how well the model's predictions align with the data, the goal is to minimize this loss function during the training process. The model should converge to an optimal solution, thus the loss function should converge to a constant value with increasing steps. If the loss still seems to decrease, then the model should be run again with more steps.

Model Fit

It is important to investigate how well Valinor is able to fit the input data (here counts). The histograms compare the distribution of the input counts and the values fitted by Valinor. If the distributions agree well, Valinor was able to fit the data well. If there is strong discrepancy between the distributions this could point that either the model didn't converge yet (run longer) or it is missing some important properties to explain the data, which requires modifications to the model.

Distributions of Model Parameters

This tab gives an overview over the distributions of the different parameters in Valinor to spot any obvious pecularities (i.e. deviations from the priors).

Guide Efficiencies

Guide Efficiencies are the ε parameters that describe the estimated probability of a guide to produce a knockout. These are estimated using hierarchical priors, thereby making use of the information in the whole dataset but still allowing for cell line specific variations for each guide.

These plots will only display data if columns such as `guide_1_eff_mean` are in the Valinor output. If they can't be found in the output these plots will be empty.

Hyper Distributions of Guide Efficiencies

The hyper distributions determine the global efficiency distribution of each guide irrespective of the cell lines. The hyper distribution of each guide is described as a normal distribution with a mean, μ, and a standard deviation, σ, which are respectively sampled from user defined priors.

For each guide in each position, Valinor fits the mean and standard deviation of the hyper distribution. Fitted values that deviate much from the priors are an indication that there is strong evidence in the data for a different hyper guide efficiency than expected from the priors. The hyper distributions of guide efficiencies are independent of cell lines.

Priors

If the priors were not set by the user, the default priors (found in valinor/priors.py) are used.

The deviation from prior is calculated by subtracting the fitted μ or σ of a guide's hyper distribution from the prior mean and devide it by the prior standard deviation.

Cell line-specific Guide Efficiencies

These cell line-specific guide efficiencies are the second and last layer in the efficiency hierarchy. From the guide-specific hyper distributions, Valinor fits cell line-specific guide efficiencies for each guide which are informed by the respective hyper distributions

The deviation from guide hyper distribution is calculated by subtracting the fitted guide efficiency in a cell line by the fitted μ and devide it by the σ of the guide-specific hyper distribution. Fitted values that deviate much from the hyper distributions are an indication that there is strong evidence in the data for a different hyper guide efficiency than expected from the priors. Special focus should be on identifying cell lines in which guide efficiencies deviate much from their hyper distributions. This could point to issues with data from that specific cell line.

If a guide is present in position 1 and 2, hyper- and cell line-specific guide efficiency distributions are fitted separately for each position for the same guide. Therefore, the plots show the efficiencies separately for each position.

Input Data Stats

This tab gives an overview over the data. This is to inform if there are any obvious pecularities in the data, that might influence the performance of Valinor.

Distribution of Counts

The density plots show the counts of guide pairs at the start of the experiment (which is often the plasmid counts) and at the end of the experiment. The density plots are split by cell line to identify obvious outliers.

Overdispersion of Replicates

The overdispersion captures the variance of counts for the same guide pair in the same cell line across replicates. Ideally the overdispersion is very small, which would indicate that the measurements are very consistent across replicates. A larger overdispersion indicates larger variability in replicate measurements. The overdispersion is used to inform the overdispersion parameter of the negative binomial distribution in Valinor, when Valinor fits the count data. Ideally overdispersion is small and consistent across cell lines. If guide pairs in replicates of one cell line are much more overdispersed compared to other cell lines, this could point towards issues with that cell line experiment.

Diagnostic Plots

This tab serves to compare the Valinor fit to expectations solely based on the data. Discrepancies can point to either inconsistencies in the data that Valinor is able to bridge or to a non-optimal fit of Valinor.

The Valinor Score is calculated as the estimated combination effect divided by the uncertainty in this value. A very negative Valinor Score means that Valinor detected strong synthetic lethality with high certainity. A positive Valinor Score points towards a rescue relationship.

dLFC vs. Valinor Score

In literature, dLFC is often used as a simple first measure of synthetic lethality. It simply adds the single-gene effects and subtracts them from the measured effect of a combination. If the effect of the combination is stronger than the sum of the two single effects, the relationship between two genes is considered synthetic lethal. In terms of CRISPR knockout screens, the log fold change (LFC) is frequently used to quantify the "effect" of knocking out either a gene pair or the respective singletons.

It is expected, that dLFC and Valinor Scores point in the same direction, but the exact magnitudes might differ. If there isn't a clear connection between dLFC and Valinor Scores, the data on the entire screen that Valinor uses gives different information compared to the basic dLFC measurement. Valinor Scores are informed by using measurements across the whole dataset. On the contrary, dLFC is calculated using only the measurements for two genes and their combination in a specific cell line ignoring information that could be gained about that specific gene pair using data from other cell lines and other combinations containing these genes.

The cell line names can be clicked to highlight points of a specific cell line. The plot can be zoomed in and moved around.

Note: It is normal for the scales, i.e. absolute values, of dLFC and Valinor Scores to be quite different. This plot just serves to explore the correlation between these two synthetic lethality measures.

Uncertainty of Estimated Combination Effect

As described above, the Valinor Score is composed of the estimated combination effect and the uncertainty on the exact magnitude of this effect. This plot shows the relationship between the uncertainty and the magnitude of the estimated combination effect, i.e. effect size. Large estimated combination effects with low uncertainty point towards measurements for which Valinor was more confident to estimate the genetic interaction effect between the gene pair.

Singleton Gene LFC vs. Estimated Single Gene Effect

These plots compare the measured LFC of Singleton constructs, i.e. measuring the effect of knocking out a single gene, with the singleton gene effect estimated by Valinor. If data and data fit agree well, Singleton LFC and gene effect should correlate well. If there is no strong correlation this indicates that by also using combination data, Valinor inferred different single gene effects than implied by the Singleton measurements. This could point to discrepancies in the Singelton versus Combination data or issues with Valinor's assumptions and configurations.

Singleton Guide LFC vs. Estimated Efficiency

These plots compare the measured LFC of each guide construct with guide efficiency estimated by Valinor. This can be instructive of which guides performed particularly well or worse. Guides that have a very negative or positive LFC in a given cell line but are estimated to have a very low efficiency could point to issues with the consistencies of measurements between guides targeting the same gene.

Hit Prioritisation

This tab provides some plots to aid the prioritisation of synergistic gene pairs for further experiments.

LFC vs. Valinor Score - Average across Cell Lines

This plot shows the Valinor Scores of all gene pairs averaged across the cell lines versus their measured LFCs. Gene pairs that are found in the lower left quadrant (green) present targets that show evidence of synthetic lethality and where the double KO produces a clear fitness deficit across cell lines. These gene pairs are likely synthetic lethal irrespective of the specific cell line.

Estimated Single Gene vs. Combination Effect

These plots help to find gene pairs where the two individual genes are estimated to have no effect on fitness (around 0) while the combination has a strong effect on fitness. For some applications it might also be relevant to select gene pairs where one individual gene already shows a fitness effect which is increased by the combination.

LFC vs. Valinor Score - Select Region

This plot is a more detailed version of the plot above. Instead of averaging over cell lines, each dot shows the measured LFC and Valinor Score of a gene pair in a given cell line. By drawing a window over a region of interest, the selected gene pairs are shown in the histogram below along with the number of cell line in which they fall in the selected window. This can help discriminate context-specific from general synthetic lethal gene pairs.

Valinor Score across Cell Lines

This plot shows the rank of the Valinor Score across all cell lines with measurements for the selected gene pair. The rank is calculated by taking the Valinor Scores of all gene pairs in a cell line and ranking them from most negative (rank 1) to most positive (highest rank). Gene pairs with very low ranks, e.g. 1-10 are among the top synthetic lethal hits in a cell line. This plot helps to highlight gene pairs that show difference in synthetic lethalities across cell line, pointing towards potential context-dependencies.

Valinor Score vs. Single Gene Effects

These plots compare the estimated single gene effects with the Valinor Score of the combination. This can help to identify in which cell lines the single genes have an effect and if in those cell lines the gene pair is synthetic lethal.

Single Gene Effects vs. Singleton LFC

These plots compare the Singleton LFC to the estimated single gene effect. If the data of Singleton and Combination measurements is consistent with Valinor's expectations then Singleton LFC and estimated single gene effect should correlate well.

Valinor Score vs. LFC

These plots help to compare the estimated Valinor Score to the measured LFC of the Singletons and the Combination in different cell lines.
